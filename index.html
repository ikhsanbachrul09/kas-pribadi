⚠️ Gagal memuat data
Terjadi kesalahan.
  • Buka Extensions → Apps Script, pilih fungsi seedData di dropdown, klik Run sekali, lalu setujui izin akses (Authorize) yang diminta Google.
  • Pastikan file HTML frontend diberi nama persis index (bukan index.html).
  • Cek koneksi internet untuk memuat library grafik (Chart.js).
  • Buka Console browser (F12) untuk detail error teknis.
